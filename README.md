# README

This is a Python implementation of GENESIS - the GENEric SImulation System for modelling state transitions, by Matthew S. Gillman.

The original version was implemented in Perl and is still [stored on Figshare](https://figshare.com/articles/dataset/GENESIS_-_the_GENEric_SImulation_System_for_modelling_state_transitions_/4775437).

Here is the [link to my JORS article](https://openresearchsoftware.metajnl.com/articles/jors.179) about it; please cite this if you wish to use GENESIS in your own research.

I hope you find it useful.
